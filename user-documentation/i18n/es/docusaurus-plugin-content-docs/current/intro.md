# Bienvenido a la Documentación de LawFlow

LawFlow es una plataforma integral de gestión de prácticas legales diseñada específicamente para despachos de abogados especializados en derecho inmobiliario en España. Construida con tecnologías web modernas, agiliza todo el proceso de transacción inmobiliaria desde la captación inicial de clientes hasta el cierre final.

## ¿Qué es LawFlow?

LawFlow combina una potente gestión de tareas con flujos de trabajo legales especializados para ayudar a los abogados de derecho inmobiliario a gestionar eficientemente:

- **Gestión de Asuntos**: Organizar compras, ventas y otras transacciones inmobiliarias
- **Automatización de Tareas**: Checklists y flujos de trabajo optimizados para diferentes tipos de transacción
- **Gestión de Documentos**: Almacenamiento seguro de archivos y organización
- **Integración de Calendario**: Seguimiento de plazos y sincronización con calendarios externos
- **Sistema de Plantillas**: Plantillas de documentos legales específicas por municipio
- **Generación de Paquetes de Cierre**: Ensamblaje automatizado de documentos y entrega al cliente

## Características Clave

### 🎯 **Diseño Centrado en el Usuario**

## Arquitectura del Sistema

LawFlow consta de dos componentes principales:

### Frontend (React/TypeScript)
- Aplicación de una sola página moderna
- Actualizaciones en tiempo real vía WebSocket
- Diseño responsivo con tema oscuro
- Arquitectura basada en componentes

### Backend (FastAPI/Python)
- API RESTful con documentación automática
- Soporte de base de datos SQLite/PostgreSQL
- Gestión de carga y almacenamiento de archivos
- Procesamiento de trabajos en segundo plano
