# Getting Started

Welcome to LawFlow! This section will help you get up and running with LawFlow quickly and efficiently.

## Quick Start

If you're new to LawFlow or want to get started immediately:

- **[Quick Start Guide](./quick-start.md)** - Get LawFlow running locally in 5 minutes with Docker (recommended for most users)

## What is LawFlow?

LawFlow is a comprehensive legal practice management system designed to streamline property law workflows. It combines task management, document handling, calendar integration, and client communication into a single, intuitive platform.

### Key Features

- **Matter Management** - Organize cases, track progress, and manage deadlines
- **Task Boards** - Visual kanban-style task management with drag-and-drop
- **Document Management** - Secure file storage with version control and collaboration
- **Calendar Integration** - Sync with Google Calendar for appointment management
- **Client Portal** - Secure client communication and document sharing
- **Reporting** - Comprehensive analytics and reporting tools

## Choose Your Setup Method

### For Users (Quick Setup)
If you just want to use LawFlow:

1. Follow the [Quick Start Guide](./quick-start.md)
2. Use Docker Compose for the easiest experience
3. Access at http://localhost:8080

### For Developers (Advanced Setup)
If you want to contribute or customize:

1. Set up the [development environment](../technical-setup/local-development.md)
2. Install dependencies manually
3. Run frontend and backend separately

## System Requirements

- **Docker & Docker Compose** (recommended)
- **Node.js 18+** and **Python 3.9+** (for manual setup)
- **4GB RAM** minimum, 8GB recommended
- Modern web browser (Chrome, Firefox, Safari, Edge)
