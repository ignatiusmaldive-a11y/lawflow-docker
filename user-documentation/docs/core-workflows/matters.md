# Matter Management

Matters are the core organizational unit in LawFlow, representing individual property transactions. Each matter contains tasks, documents, deadlines, and all related information for a specific purchase or sale.

## Overview

LawFlow supports different types of matters:

- **Purchases** (Compra) - Buying property
- **Sales** (Venta) - Selling property
- **Other Transactions** - Mortgages, gifts, etc.

## Creating a New Matter

### Step 1: Access Matter Creation

Click the **+ New Matter** button in the sidebar or use the quick add modal (`Ctrl+N`).

### Step 2: Choose Transaction Type

Select the appropriate transaction type:

- **Purchase** - For buying property
- **Sale** - For selling property

### Step 3: Enter Basic Information

Fill in the required details:

- **Property Address** - Full address of the property
- **Client Information** - Buyer's/seller's details
- **Transaction Value** - Purchase/sale price
- **Municipality** - Marbella, Mijas, Estepona, etc.
- **Expected Completion Date** - Target closing date

### Step 4: Configure Settings

- **Color Theme** - Choose a background color for visual organization
- **Priority Level** - High, Medium, Low
- **Assign Team Members** - Legal team working on the matter

## Matter Dashboard

Once created, each matter has its own dashboard with:

### Task Board
- **Kanban-style** task management
- **Columns**: To Do, In Progress, Review, Done
- **Drag & drop** task movement
- **Due date tracking** with visual indicators

### Timeline View
- **Phase-based** progress tracking
- **Milestones** with completion dates
- **Gantt chart** visualization
- **Critical path** highlighting

### File Room
- **Document organization** by category
- **Drag & drop** uploads
- **File previews** and thumbnails
- **Secure sharing** with clients

## Switching Between Matters

### Sidebar Navigation

The sidebar shows your active matters with:

- **Color-coded** backgrounds for quick identification
- **Status indicators** (active, pending, completed)
- **Pinned matters** for frequent access
- **Recent matters** list

### Quick Switching

- Click any matter in the sidebar to switch
- Use the matter selector dropdown in the top bar
- Keyboard shortcut: `Ctrl+M` to open matter switcher

## Matter Status Tracking

### Status Types

- **Active** - Currently working on
- **Pending** - Waiting for external input
- **On Hold** - Temporarily paused
- **Completed** - Successfully closed
- **Cancelled** - Terminated transaction

### Status Updates

Status automatically updates based on:
- Task completion percentage
- Key milestone achievements
- Manual status changes by team members

## Background Color Customization

### Purpose

Color coding helps with:
- **Visual organization** across multiple matters
- **Quick identification** in sidebar and task board
- **Team coordination** for matter assignment

### How to Change

1. Open the matter settings
2. Navigate to "Appearance" tab
3. Select from predefined color palette
4. Colors sync across all team members

## Advanced Matter Features

### Matter Templates

Create templates for common transaction types:

- **Standard Purchase** - Basic purchase workflow
- **Off-Plan Purchase** - For new developments
- **Investment Purchase** - Commercial properties
- **Custom Templates** - Organization-specific workflows

### Matter Cloning

Duplicate existing matters for:
- **Similar transactions** in the same area
- **Template creation** for repeated workflows
- **Backup purposes** before major changes

### Bulk Operations

Perform actions on multiple matters:
- **Status updates** for batch processing
- **Team reassignment** during staff changes
- **Archive old matters** for cleanup

Track important KPIs:

### Reporting

Generate reports for:

4. **Team assignments** - Clearly define responsibilities

### Workflow Optimization

1. **Template usage** - Leverage templates for efficiency
2. **Regular reviews** - Weekly matter status meetings
3. **Deadline monitoring** - Set realistic completion dates
4. **Client communication** - Keep clients updated on progress

## Troubleshooting

### Common Issues

**Matter not loading?**
- Check internet connection
- Clear browser cache
- Try refreshing the page

**Changes not saving?**
- Verify you have edit permissions
- Check for conflicting edits by team members
- Ensure required fields are completed

**Tasks not appearing?**
- Confirm matter is set to "Active" status
- Check task filters and search
- Refresh the task board
